Inside Chandra

A governed flow
from signal to proof.

Named items in the canvas are system capabilities and workflows. The KRA set is configurable for each customer and operating environment.

01 / INTAKE

Connect

AWS accounts, tickets, webhooks and approved operational inputs.

02 / OBSERVE

Observe

Inspect the configured KRA set using deterministic cloud checks.

03 / CLASSIFY

Classify

Group findings and surface the issues that deserve attention first.

04 / DECIDE

Explain

Prepare the impact, recommendation, risk and expected outcome.

05 / GOVERN

Approve

A Human Approval Checkpoint pauses high-risk changes for review.

06 / VERIFY

Prove

Execute approved work, verify the result and publish the brief.
